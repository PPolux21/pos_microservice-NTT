# Grocery Inventory POS Master Class
Production-oriented Spring Boot 3.x microservice using Java 21, SQL Server, Docker, REST APIs, validation, JPA, OpenAPI, Lombok, MapStruct, tests, and CI/CD. Run: `docker compose up --build`. Swagger: `http://localhost:8080/swagger-ui.html`. Default Basic Auth: `admin/admin123`.
